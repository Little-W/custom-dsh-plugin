# 数据存储管理

在插件设置中选择 DSH 数据的存储位置。使用“复制并切换”迁移会话、缓存、插件数据及桌面版数据；profiles 和启动配置会留在原位置，保证 DSH 能正常启动。桌面版安装状态、宿主工具、工作台及其他桌面目录也会随数据目录一起迁移，并在旧位置保留原路径入口。

如果目标目录已有 Web 版数据，但缺少当前桌面版或其他数据项，“切换”会提示缺失内容，并提供“合并缺失数据”。合并会补入目标目录不存在的内容；同名文件以目标目录为准，原数据完整保留在旧数据副本中。合并和切换后请重启 DSH，确认会话、桌面功能和插件都正常后，再手动清理旧副本。

插件也可以把数据打包下载为 `.tar.gz` 文件，或从备份文件恢复。备份可能包含会话和提供商设置，请妥善保管。恢复数据后需要重启 DSH。
