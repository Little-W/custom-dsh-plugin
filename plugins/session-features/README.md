# 会话功能增强

排队消息使用 DSH 原生 inbox 会话日志保存。客户端退出、会话实例释放或异常中断后，重新打开原会话会从日志恢复尚未处理的队列，保留消息顺序和附件；打开会话不会自动发送它们。提交、编辑和移除排队消息后，服务器在持久化完成后才返回成功确认；已领取或明确移除的消息不会被插件重新入队。插件卸载时，现有会话仍保留退出保护直到该会话实例释放，避免关闭客户端时先卸载插件、后清空队列。

保存会话中的 TodoList / TaskPlan，并支持从检查点继续暂停或意外中断的会话。已完成的对话步骤、工具结果、任务状态和子智能体会话保留在 DSH 会话日志及工作流检查点中；恢复时从未完成处继续，不从头重跑已完成步骤。“继续会话”使用不会进入模型上下文的内部唤醒信号，并优先处理该信号，保留等待发送的用户消息。临时网络中断由 DSH 的原生重试扩展在同一模型步骤内恢复原请求，不会创建新用户消息或重跑已经完成的步骤。

支持对普通文本用户消息执行“撤回并编辑”或“重新发送”。操作会从目标消息之前创建一个会话分支，原会话及后续记录仍保留；编辑模式将原文放入新分支输入框，重新发送模式会在新分支自动提交原文。首条消息之前没有可继承的历史，操作会新建会话。含图片或文件附件的消息不会被静默截断，需在新会话中手动补充附件。正在运行的会话暂不允许创建消息分支。

一级运行组保持原有的展开与收起方式。组内多条思考记录会收拢到单独的二级“思考”组，展开一级组后仍可独立展开思考记录；工具内容和一级组的操作不受影响。

二级思考汇总固定在一级组内容的最前面，滚动时保持在组内顶部。流式更新复用同一个汇总按钮，通过独立样式控制思考显隐，不改写 DSH 原生折叠属性，避免新气泡更新时闪烁、漏出或改变折叠状态。

插件及其包含的模块设置提供“隐藏全部思考气泡”开关（`hideAllThoughts`，默认关闭）。开启后隐藏所有思考内容及汇总入口，保留工具、回复正文和一级组操作；通过 DSH 原生设置保存并即时应用，重新启动后仍保留。关闭后恢复分组显示。

任务清单由本插件直接管理，并作为 `todo/write` 快照保存在各自的 DSH 会话日志中。DSH 原生投影会在新一轮开始时暂时清空列表；本插件会在模型执行前从当前会话日志恢复它。

插件在 DSH 原生 AgentLoop 上附加任务清单持久化、检查点状态 API 和恢复按钮，也不会替换或关闭 DSH 的会话生命周期服务。工作流会从原运行检查点继续，保留已完成节点和子智能体状态；普通会话从原生会话日志恢复。若插件未启用或未能加载，原生会话创建与恢复仍由 DSH 负责。

队列恢复回归测试使用桌面端实际依赖，在临时目录中运行，不接触用户会话：

```sh
DSH_TEST_RUNTIME=/path/to/dsh-desktop node --test plugins/session-features/queue-*.test.js
```

覆盖原生清空队列问题复现、关闭插件后退出、跨运行时恢复、队列编辑与移除、附件与引导消息、落盘失败、调用方上下文保留，以及成功确认后立即 `SIGKILL` 的进程恢复。
