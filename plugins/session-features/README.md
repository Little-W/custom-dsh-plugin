# 会话功能增强

保存会话中的 TodoList / TaskPlan，并支持从检查点继续暂停或中断的会话。“继续会话”使用不会进入模型上下文的内部唤醒信号，不再追加恢复提示词。临时网络中断由 DSH 的原生重试扩展在同一模型步骤内恢复原请求，不会创建新用户消息或重跑已经完成的步骤。

任务清单由本插件直接管理，并作为 `todo/write` 快照保存在各自的 DSH 会话日志中。DSH 原生投影会在新一轮开始时暂时清空列表；本插件会在模型执行前从当前会话日志恢复它，不依赖 OpenCode 提供商插件。

插件在 DSH 原生 AgentLoop 上附加任务清单持久化和会话检查点唤醒能力，不替换或关闭 DSH 的会话生命周期服务。若插件未启用或未能加载，原生会话创建与恢复仍由 DSH 负责。
