# 会话功能增强

保存会话中的 TodoList / TaskPlan，支持暂停后从原进度继续；网络意外中断或超时时，按递增间隔自动重试最多 3 次。恢复时沿用现有会话记录，保留已完成的工具结果，并检查实际状态以避免重复执行。超过重试次数后，仍可使用输入栏的“继续会话”按钮手动恢复。

任务清单由本插件直接管理，并作为 `todo/write` 快照保存在各自的 DSH 会话日志中。DSH 原生投影会在新一轮开始时暂时清空列表；本插件会在模型执行前从当前会话日志恢复它，不依赖 OpenCode 提供商插件。

插件在 DSH 原生 AgentLoop 上附加这些能力，不替换或关闭 DSH 的会话生命周期服务。若插件未启用或未能加载，原生会话创建与恢复仍由 DSH 负责。
