# OpenCode 模型服务

连接 OpenCode 提供的模型，并在工作台中查看模型列表、选择模型和调整模型参数。网络中断或响应流意外结束时，适配器将错误交回 DSH 原生重试机制，在同一 turn/step 重放当前检查点，不会追加模型提示词。插件包已内置 OpenCode 2.2.5 服务端与 Effect 运行时代码；安装时只需解析清单中列出的 DSH 官方接口及原生运行依赖，不依赖 Agent Studio 工作区或单独安装 `@opencode/*` 包。为避免安装数百 MB 的额外二进制，插件不包含独立 Claude Agent 执行器；通过 OpenCode 调用模型的功能不受影响。关闭后，工作台会使用 DSH 自带的模型服务。
