# Codex 编程助手

启用后会添加 Codex 编程提示，优先通过 shell 和文件工具直接完成工作。插件要求先从目录列表或搜索结果确认文件路径，再读取文件；确认路径后的独立读取可以并行。它保留 DSH 原版 Bash 工具及其作业管理，并减少逐条播报检查过程。

插件还补充了有输出上限的目录列表；读取不存在的路径时，会明确指出未读取到内容，并附上有限的父目录条目，避免模型根据相似文件名猜路径。文件搜索遇到无效正则时会按字面文本重试，读取行号超出文件范围时会调整到有效位置。SVG 图片会先经过安全检查，再渲染为 PNG 预览供支持图片输入的模型查看。

复杂任务会采用精简的阶段计划；上下文压缩后，如果文件路径依据已不可见，会重新进行小范围探测。搜索空结果按当前检索范围内无匹配处理，不据此推断文件内容，也避免重复相同的失败查询。Goal 提示遵循 DSH 的权限边界：只有顶层智能体正在处理用户直接消息时才执行目标变更，恢复轮次和子智能体由目标驱动器处理。Windows 使用 PowerShell，其他系统使用 DSH Bash。
