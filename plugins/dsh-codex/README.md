# Codex 编程助手

启用后会添加 Codex 编程提示，优先通过 shell 和文件工具直接完成工作。互不依赖的只读检查可以并行执行；插件保留 DSH 原版 Bash 工具及其作业管理，并减少逐条播报检查过程。

插件还补充了目录内容列表工具；文件搜索遇到无效正则时会按字面文本重试，读取行号超出文件范围时会调整到有效位置。SVG 图片会先经过安全检查，再渲染为 PNG 预览供支持图片输入的模型查看。

复杂任务会采用精简的阶段计划；搜索空结果按当前检索范围内无匹配处理，不据此推断文件内容，也避免重复相同的失败查询。Goal 提示遵循 DSH 的权限边界：只有顶层智能体正在处理用户直接消息时才执行目标变更，恢复轮次和子智能体由目标驱动器处理。Windows 使用 PowerShell，其他系统使用 DSH Bash。
